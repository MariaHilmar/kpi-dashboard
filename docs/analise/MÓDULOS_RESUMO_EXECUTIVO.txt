2. PADRÃO DE NOMENCLATURA
================================================================================

Formato Padrão:
    [MÓDULO] (ÁREA FUNCIONAL) - Descrição da Issue

Exemplos:
    [Gestão de Atas] (Sincronização) - Corrigir hash de verificação

    [Fiscalização] (Relatórios) - Gerar relatório mensal
    [Fornecedor] (Cadastro) - Adicionar campo de ramo de atividade

Componentes:
    • [MÓDULO]        - Nome do módulo entre colchetes
    • (ÁREA)          - Área funcional entre parênteses
    • Descrição       - Texto livre após parênteses

4. PADRÕES DE COMMIT
================================================================================

Formato Git Log:
    hash | autor | email | data_iso | mensagem_resumida

Prefixos Detectados:
    • fix:       - Correção de bugs (muito frequente)
    • feat:      - Novas funcionalidades (muito frequente)
    • docs:      - Documentação (frequente)
    • refactor:  - Refatoração (ocasional)
    • test:      - Testes (ocasional)
    • ci:        - CI/CD (raro)
    • [Livre]    - Mensagens não-padronizadas (raro)

Período de Coleta: Últimos 30 dias (configurável)
Dados Coletados: Hash, Autor, Email, Data ISO 8601, Mensagem
